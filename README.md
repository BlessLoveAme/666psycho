# Portfolio Site

Сайт-визитка с админ-панелью. Material Design 3 Expressive. Направления: музыка и IT.

## Запуск

```bash
npm install
npm start
```

- Сайт: http://localhost:3000
- Админ-панель: http://localhost:3000/admin.html

Логин по умолчанию: `admin` / `admin` — **смените пароль в админке** сразу после первого входа.

## Структура

```
server.js              Express-сервер, API, сессии, загрузка файлов
package.json
data/
  content.json         Контент сайта (заполняется из админки)
  users.json           Хеши паролей
public/
  index.html           Главная страница
  admin.html           Админ-панель
  styles.css           Стили MD3 Expressive
  script.js            Логика главной (загрузка контента, применение темы)
  admin.js             Логика админки (авторизация, сохранение, смена пароля)
  uploads/             Загруженные фоновые изображения
```

## Что можно менять из админки

- Имя, подзаголовок, текст «О себе»
- Заголовок, описание и список пунктов для секций «Музыка» и «IT»
- Контакты: email, Telegram, Instagram, GitHub
- Тема: основной, второстепенный, дополнительный цвета и цвет фона
- Фоновое изображение (загрузка файла + переключатель вкл/выкл)
- Пароль администратора

Списки пунктов вводятся по одному элементу на строку.

## API

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/api/content` | открытый | Получить контент сайта |
| POST | `/api/login` | открытый | Вход: `{username, password}` |
| POST | `/api/logout` | открытый | Выход |
| GET | `/api/check-auth` | открытый | Проверка сессии |
| POST | `/api/content` | требует входа | Сохранить контент |
| POST | `/api/upload-background` | требует входа | Загрузка фонового изображения |
| POST | `/api/change-password` | требует входа | Смена пароля: `{currentPassword, newPassword}` |

## Перед публикацией в интернете

1. Смените пароль в админке.
2. Замените секрет сессии в `server.js`:
   ```js
   secret: 'change-this-secret-in-production',
   ```
   на длинную случайную строку.
3. Поставьте сайт за HTTPS-прокси (nginx, Caddy) — пароль передаётся по HTTP в открытом виде при локальном запуске.
4. Файлы в `data/` и `public/uploads/` должны быть недоступны извне напрямую.

## Замечание

Файлы в `data/` и `public/uploads/` — это пользовательские данные и загруженные изображения, они специально включены в копию проекта.
