# Portfolio Site

Сайт-визитка с админ-панелью. Material Design 3 Expressive. 

## Локальный запуск

```bash
npm install
npm start
```

- Сайт: http://localhost:3000
- Админ-панель: http://localhost:3000/admin.html

Логин по умолчанию: `admin` / `admin` — **смените пароль в админке** сразу после первого входа.

## Деплой на Vercel

### 1. Установите Vercel CLI

```bash
npm i -g vercel
```

### 2. Создайте Vercel KV базу данных

1. Откройте https://vercel.com/dashboard
2. Перейдите в **Storage** → **Create Database** → **KV**
3. Назовите базу `portfolio-kv` и создайте
4. После создания Vercel автоматически добавит переменные окружения к вашему проекту

### 3. Задеплойте проект

```bash
vercel
```

При первом деплое:
- Выберите **Create a new project**
- Свяжите с созданной KV базой данных
- Vercel автоматически установит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`

### 4. Добавьте переменную SESSION_SECRET

В настройках проекта на Vercel:
1. Перейдите в **Settings** → **Environment Variables**
2. Добавьте `SESSION_SECRET` со случайным значением (например, сгенерируйте через `openssl rand -base64 32`)

## Структура

```
server.js              Express-сервер с поддержкой Vercel KV
vercel.json           Конфигурация для Vercel
package.json
public/
  index.html           Главная страница
  admin.html           Админ-панель
  styles.css           Стили MD3 Expressive
  script.js            Логика главной (загрузка контента, применение темы)
  admin.js             Логика админки (авторизация, сохранение, смена пароля)
```

## Что можно менять из админки

- Имя, подзаголовок, текст «О себе»
- Заголовок, описание и список пунктов для секций «Музыка» и «IT»
- Контакты: email, Telegram, Instagram, GitHub
- Тема: основной, второстепенный, дополнительный цвета и цвет фона
- Фоновое изображение (загрузка файла, сохраняется как base64)
- Пароль администратора

Списки пунктов вводятся по одному элементу на строку.

## API

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| GET | `/api/content` | открытый | Получить контент сайта |
| POST | `/api/login` | открытый | Вход: `{username, password}` |
| POST | `/api/logout` | открытый | Выход |
| GET | `/api/check-auth` | открытый | Проверка сессии |
| POST | `/api/content` | требует входа | Сохранить контент |
| POST | `/api/upload-background` | требует входа | Загрузка фонового изображения |
| POST | `/api/change-password` | требует входа | Смена пароля: `{currentPassword, newPassword}` |

## Особенности Vercel-версии

- **Хранилище**: Данные хранятся в Vercel KV (Redis), а не в файлах
- **Фоновые изображения**: Сохраняются как base64 в KV вместе с контентом (ограничение ~4.5MB)
- **Локальная разработка**: Работает с in-memory хранилищем без необходимости подключения к KV
- **Serverless**: Каждый запрос обрабатывается независимо

## Устранение проблем

**"Failed to change password" на Vercel:**
- Убедитесь, что Vercel KV база данных создана и подключена
- Проверьте наличие переменных окружения `KV_REST_API_URL` и `KV_REST_API_TOKEN`

**Сессии не сохраняются:**
- Добавьте переменную `SESSION_SECRET` в настройках Vercel

**Изображение слишком большое:**
- Vercel KV имеет лимит ~4.5MB на запись
- Уменьшите размер изображения перед загрузкой
